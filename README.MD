HR Recruiter Telegram Bot
📋 О проекте
Telegram-бот для автоматизации первичного отбора кандидатов. Бот позволяет кандидатам заполнять резюме в структурированном виде, автоматически анализирует данные и предоставляет HR-специалистам удобный инструмент для управления заявками.

✨ Основные функции
Для кандидатов:
📝 Заполнение структурированного резюме через пошаговый опрос

📄 Автоматическая генерация резюме в формате PDF

📊 Проверка статуса заявки по номеру

🎯 Получение советов для успешного собеседования

📋 Скачивание шаблона резюме для ручного заполнения

Для администраторов (HR):
👨‍💼 Панель управления с интерактивным меню

📋 Просмотр всех заявок с фильтрацией по статусам

✅ Изменение статусов заявок (принять/отклонить/на рассмотрении)

📊 Статистика по заявкам с аналитикой

📥 Скачивание PDF-резюме для каждого кандидата

📤 Экспорт данных в CSV-формат

🆕 Быстрая обработка новых заявок

🛠 Технологический стек
Язык программирования: Python 3.9+

Фреймворк для бота: Aiogram 3.x

База данных: SQLite 3

Генерация PDF: ReportLab

Хранение данных: Локальная БД (файл database.db)

🚀 Быстрый старт
1. Предварительные требования
Python 3.9 или выше

Аккаунт в Telegram

Токен бота от @BotFather

2. Установка и настройка
bash
# 1. Клонируйте репозиторий или скопируйте файлы проекта
# 2. Перейдите в директорию проекта
cd hr_recruiter_bot

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Отредактируйте .env файл, добавив ваш токен бота
# Откройте .env в текстовом редакторе и замените:
# BOT_TOKEN=ваш_токен_бота_здесь
3. Получение токена бота
Откройте Telegram

Найдите бота @BotFather

Отправьте команду /newbot

Следуйте инструкциям:

Придумайте имя бота (например, HR Recruiter Bot)

Придумайте username бота (например, my_hr_recruiter_bot)

Скопируйте полученный токен (выглядит как 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz)

Вставьте токен в файл .env

4. Получение вашего Telegram ID
Откройте Telegram

Найдите бота @userinfobot

Отправьте команду /start

Бот покажет ваш ID (например, 123456789)

Откройте config.py и замените ADMIN_ID на ваш ID

5. Запуск бота
bash

# 1. Запустите бота
python main.py
6. Первый запуск
При первом запуске:

✅ Создастся база данных data/database.db

✅ Создадутся необходимые таблицы

✅ Вы увидите сообщение "Бот запущен!" в консоли

✅ Бот будет готов к работе

📱 Использование бота
Для кандидатов:
Начало работы: Напишите /start боту

Заполнение резюме: Отправьте команду /anketa и следуйте инструкциям

После заполнения: Вы получите номер заявки и PDF-файл с резюме

Проверка статуса: Отправьте номер заявки (например, #1)

Шаблон резюме: Команда /template - получите PDF для ручного заполнения

Для администраторов:
Вход в админку: Отправьте /admin

Авторизация: Введите пароль (по умолчанию: admin123)

Основное меню: Появятся кнопки управления

Управление заявками:

📋 Все заявки - просмотр всех резюме

🆕 Новые заявки - только непросмотренные

📊 Статистика - аналитика по заявкам

📥 Экспорт - выгрузка данных в CSV

⚙️ Настройка и кастомизация
Конфигурационный файл (config.py):
python
BOT_TOKEN = "ваш_токен_бота"  # Токен от @BotFather
ADMIN_PASSWORD = "admin123"    # Пароль для доступа к админке
ADMIN_ID = 123456789          # Ваш Telegram ID (для автоматического доступа)
База данных:
База данных хранится в файле data/database.db и содержит:

Таблица resumes:

ID заявки

Данные кандидата (ФИО, телефон, ВУЗ, зарплата и т.д.)

Статус заявки (new, review, accepted, rejected)

Дата создания

Автоматическое создание: Таблицы создаются при первом запуске

Безопасность:
Пароль админки: Измените ADMIN_PASSWORD в config.py

Доступ по ID: Только указанный ADMIN_ID имеет мгновенный доступ

Другие пользователи: Могут получить доступ по паролю

Рекомендация: Регулярно меняйте пароль в продакшн-среде
